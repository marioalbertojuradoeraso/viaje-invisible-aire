# El Viaje Invisible del Aire

Recurso didáctico interactivo en 9 paradas sobre contaminación atmosférica: de las capas de la atmósfera a la calidad del aire interior.

**Autor:** Profesor Mario Alberto Jurado Eraso · Curso de Química ambiental · Universidad de Nariño

Sitio web estático (HTML + Tailwind CSS), sin backend ni claves de API. Las voces (ElevenLabs) y los fondos (BFL) fueron pre-generados.
